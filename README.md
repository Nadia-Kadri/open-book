# Open Book

Open Book is a web application that allows users to browse through a curated collection of books along with personal reviews. The application also features an admin dashboard for managing the book entries.

## Features

+ User View: Explore the book collection with cover images fetched from the Open Library Covers API.
+ Admin Dashboard: Securely login to add or remove books from the collection.
+ Authentication: Protected routes for admin access, secured using Passport.js.
+ Search Bar: Easily search for books by title when adding new books to the collection via the admin dashboard.

## Tech Stack

+ Frontent: JavaScript, EJS, Bootstrap
+ Backend: Node.js, Express, PostgreSQL, Passport.js
+ APIs: Open Library Covers API
